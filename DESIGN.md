# AbleBounce visual system

Mode: Operate. A session-delivery workbench with a persistent track-role tree,
nine compact export rows, and a visible format/output inspector. No dashboard
metrics, marketing illustrations or decorative meters.

Light ivory #F6F5F0 canvas; ink #182321; deep green #183B32 connection/primary
controls; acid yellow #D7F36B selected jobs and main action; coral #D25B42 lead
role; green #39725F backing role; muted text #58635C; dividers #DBDED5.
Native Segoe UI Variable/Segoe UI for a Windows working application. 14px body,
12px secondary text, 26px project title. Eight-pixel spacing base. 40px minimum
control height, obvious keyboard focus, readable disabled/error states. Icons
are authored WPF paths. Primary action remains visible; long track lists scroll.

Default window 1280x860, minimum 1060x740. Header 78px, footer 92px, tree 290px,
settings 250px, flexible job column. Every demonstration is marked Demo; initial
real mode contains no synthetic project. Reduced motion: no continuous animation.

Signature interaction: selecting an export row reveals its exact vocal and
master state; role edits immediately update the delivery plan before any render.
